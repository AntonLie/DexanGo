# DexaGo

DexaGo is a Web App for Employee WFH Attendance & HRD Monitoring, built as a fullstack **Aplikasi Absensi WFH Karyawan** + **Aplikasi Monitoring Karyawan**.

Please Visit Web :

- Employee Portal -> [https://employee-web-zeta.vercel.app](https://employee-web-zeta.vercel.app)
- HRD Admin Portal -> [https://admin-web-six-mocha.vercel.app](https://admin-web-six-mocha.vercel.app)
